# Human Plus 1.0.0

**Неофіційний клієнт для HUMAN Школа** для Windows. Усе важливе для учня на одному екрані: розклад дня, що задано, що не виконано, оцінки.
Лише читання. Не пов'язаний із компанією HUMAN; «Plus» означає надбудову над HUMAN (зручніший погляд на ті самі дані), а не платний тариф.

## Що вміє

- **Сьогодні:** таймлайн уроків; клік по уроку розкриває «Заняття» (матеріали) та «Завдання» (що задано) з повним змістом.
- **На наступний урок**, **Усі завдання** (фільтри, групування, прострочене виділене), **Розклад**, **Оцінки**.
- Увесь вміст усередині застосунку: текст, фото, посилання, файли (зберігаються в «Завантаження» за кліком), формули, таблиці.
- Точні статуси завдань, як на вкладці «Завдання» оригіналу.
- Міні-режим «Що задано на завтра» (Ctrl+Shift+H), лічильник у треї й на панелі завдань, сповіщення про дедлайни.
- Світла/темна теми, власні кольори, «скляні» ефекти (Windows 11 Mica/Acrylic) із запасним режимом без прозорості.
- Працює лише для ролі «учень»; для вчителя й невизначеної ролі показує «Додаток доступний лише для учнів».

## Чого не робить

- Не здає завдань, не змінює даних, не пише повідомлень: до HUMAN іде лише `GET`.
- Не бачить і не зберігає пароль чи токени: ви входите самі на справжній сторінці HUMAN у вікні застосунку.
- Не збирає телеметрію; звертається лише до `*.human.ua`. Докладніше: PRIVACY.md та docs/API-USAGE.md.

## Як встановити

1. Завантажте **`Human Plus-Setup-1.0.0.exe`** (інсталятор) або **`Human Plus-portable-1.0.0.exe`** (без встановлення).
2. Запустіть файл. Windows SmartScreen покаже синє вікно «Windows захистила ваш ПК», бо застосунок **не підписаний** сертифікатом розробника
   і є неофіційним. Натисніть **«Докладніше»**, потім **«Виконати в будь-якому разі»**.
3. У застосунку натисніть «Увійти» і увійдіть у HUMAN (пошта/пароль або Microsoft).

Видалити всі локальні дані (куки сесії та кеш): Налаштування → «Вийти й стерти дані».

## Відомі обмеження і ризики

- API HUMAN **недокументоване** і може змінитися; тоді частина секцій деградує, а застосунок покаже, що вдалося.
- Не перевірено на реальному акаунті вчителя (відмова спирається на перелічення ролей із коду фронтенду та юніт-тести).
- Скасування, перенесення й заміни уроків у тестовому акаунті були порожні; розбір захисний, за кодом фронтенду.
- Збірка не підписана, автооновлення немає. Скляні ефекти Mica/Acrylic працюють у Windows 11 22H2+; на Windows 10 — суцільний фон.
- Значок застосунку — векторне відтворення наданої аватарки.
