# Участь у розробці

Дякуємо за інтерес! Проєкт навмисно мінімальний: Electron + ванільні HTML/CSS/JS (ES modules), без фреймворків і бандлерів.

## Запуск

```bash
npm ci
npm run demo   # без акаунта, на синтетичних даних
npm start      # справжній режим: ви входите самі на сторінці HUMAN
npm test       # юніт-тести
npm run lint   # eslint
npm run format # prettier
```

## Правила

- **Лише читання.** Жодних `POST/PUT/PATCH/DELETE` до HUMAN. Жодних здач завдань чи повідомлень.
- Усе, що знає про формат HUMAN, живе в `src/api.js`, `src/blocks.js`, `src/normalize.js`. UI працює лише з внутрішньою моделлю.
- Усі рядки інтерфейсу — в `src/uk.js`, українською. Множину робимо через `Intl.PluralRules('uk')`.
- Дані з API потрапляють у DOM лише через `textContent` або санітизований HTML. Нові домени додаються лише в `src/allowlist.js` разом із тестом.
- Не додавайте залежностей без потреби. Не логуйте персональні дані й не додавайте телеметрію.
- Нова поведінка — з тестом (`test/*.test.js`). Скриншоти — лише з демо-даних.
- Семантичне версіонування, зміни — в `CHANGELOG.md`.
